# TikTok Shop选品指南

## TikTok Shop选品核心原则

TikTok Shop与传统电商平台最大的区别在于**内容驱动**。产品能否卖好，很大程度上取决于能否通过短视频或直播展示出吸引人的效果。

### 选品三大原则

1. **视觉冲击力强**：产品在视频中要有明显的"wow"效果
2. **价格敏感度低**：TikTok用户更看重有趣而非便宜
3. **易于展示**：能在15-60秒内完整展示产品价值

## 2026年爆款品类

### 1. 美妆个护（占比35%）

**热门产品**：
- 美妆蛋、化妆刷套装
- 口红、眼影盘
- 护肤仪器（黑头仪、导入仪）
- 假睫毛、美瞳

**成功案例**：
- 某品牌美妆蛋，通过"水浸膨胀"视频，单月销量破10万件
- 口红试色视频，配合"变色唇膏"卖点，转化率高达8%

**选品建议**：
- 选择颜色鲜艳、效果明显的产品
- 避免需要长时间使用才能见效的产品
- 包装要"上镜"，适合短视频拍摄

### 2. 家居收纳（占比25%）

**热门产品**：
- 压缩袋、收纳盒
- 厨房小工具（切菜器、剥皮器）
- 创意挂钩、置物架
- 清洁工具（电动刷、拖把）

**成功案例**：
- "一秒收纳"系列视频，展示压缩袋使用前后对比，播放量超千万
- 厨房切菜器，通过"切洋葱不流泪"痛点，月销5万件

**选品建议**：
- 强调"解决痛点"而非"功能丰富"
- 选择使用前后对比明显的产品
- 避免需要复杂安装的产品

### 3. 服饰配饰（占比20%）

**热门产品**：
- 首饰（项链、耳环、戒指）
- 帽子、围巾
- 袜子、内衣
- 眼镜、太阳镜

**成功案例**：
- "变色项链"配合温度变色效果，单条视频带货3000件
- 个性袜子，通过"穿鞋露出"展示，复购率高达40%

**选品建议**：
- 选择款式新颖、容易搭配的产品
- 避免尺码复杂的服装（退货率高）
- 配饰类产品利润率更高

### 4. 3C数码（占比10%）

**热门产品**：
- 手机壳、数据线
- 蓝牙耳机
- 充电宝
- 智能手表配件

**成功案例**：
- 创意手机壳（磁吸、支架功能），通过"手机秒变平板"视频爆火
- 快充数据线，展示"30分钟充满"效果

**选品建议**：
- 选择有"黑科技"感的产品
- 避免需要复杂说明的产品
- 配件类产品竞争激烈，要有差异化卖点

### 5. 玩具礼品（占比10%）

**热门产品**：
- 解压玩具（捏捏乐、指尖陀螺）
- 创意礼品（夜灯、投影仪）
- 毛绒玩具
- 盲盒

**成功案例**：
- "解压捏捏乐"，通过"捏爆解压"视频，月销8万件
- 星空投影灯，配合"浪漫氛围"场景，转化率6%

**选品建议**：
- 选择有"惊喜感"的产品
- 玩具类产品季节性强，注意备货节奏
- 避免易损坏的产品

## 选品避坑指南

### 不适合TikTok Shop的产品

1. **需要复杂说明的产品**：用户没耐心看完
2. **使用效果不明显的产品**：视频无法展示价值
3. **价格过高的产品**：TikTok用户冲动消费为主
4. **易损坏的产品**：售后成本高
5. **季节性太强的产品**：库存风险大

### 定价策略

**TikTok Shop最佳价格区间**：
- 美妆个护：$5-30
- 家居收纳：$8-25
- 服饰配饰：$3-20
- 3C数码：$10-50
- 玩具礼品：$5-30

**定价公式**：
```
售价 = 成本 × 3-5倍
（包含：产品成本 + 物流 + 平台佣金 + 营销成本 + 利润）
```

## 成功选品案例拆解

### 案例1：美妆蛋套装

**产品**：10个装美妆蛋 + 清洗托盘
**成本**：$2.5
**售价**：$12.99
**卖点**："干湿两用，遇水膨胀3倍"
**视频策略**：
- 前3秒：展示美妆蛋干瘪状态
- 中间：浸水后瞬间膨胀
- 结尾：上妆效果对比
**结果**：单月销量10万件，ROI 1:8

### 案例2：厨房切菜器

**产品**：5合1切菜器
**成本**：$3
**售价**：$14.99
**卖点**："切洋葱不流泪，10秒切完一盘菜"
**视频策略**：
- 痛点开场：切洋葱流泪画面
- 产品展示：10秒切完洋葱
- 对比效果：手切vs机器切
**结果**：月销5万件，复购率25%

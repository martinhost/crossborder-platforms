## Shopee入驻条件

### 1. 企业资质
- 中国大陆或香港营业执照（企业或个体工商户均可）
- 营业执照需在有效期内，无经营异常
- 法人身份证正反面照片
- 法人手持身份证照片

### 2. 联系方式
- 未注册过Shopee的手机号
- 未注册过Shopee的邮箱
- 建议使用法人实名手机号

### 3. 收款账户
- 连连支付、PingPong、Payoneer任选其一
- 账户持有人姓名需与营业执照法人一致

### 4. 其他材料（可选）
- 近3个月跨境电商平台流水（加分项）
- 品牌授权/商标证（做品牌店必备）

## Shopee入驻流程

1. **创建主账户**：访问Shopee官网，注册主账户
2. **提交入驻信息**：填写公司信息、法人信息
3. **法人验证**：上传身份证照片，录制认证视频
4. **填写详细资料**：上传营业执照，填写公司地址
5. **等待审核**：3-5个工作日
6. **缴纳保证金**：3000元人民币
7. **绑定收款账户**：绑定连连支付等收款账户
8. **完成新手任务**：上架50个商品

## Shopee费用结构

### 1. 保证金
- 3000元人民币（同一营业执照）
- 退店时可全额退还

### 2. 平台佣金
- 普通店铺：6%-10%
- 新店免佣：前3个月免佣金（2026年政策）

### 3. 交易手续费
- 0.5%-2%（按订单金额）

### 4. 物流费
- SLS物流：按重量和目的地计算
- 国内段：卖家承担
- 国际段：平台承担

### 5. 提现手续费
- 连连支付：0.5%-1%
- 每周可提现

## Shopee运营技巧

### 1. 选品策略
- 721法则：70%引流款 + 20%利润款 + 10%潜力款
- 轻小件、低客单、高复购率品类
- 避开大件、液体、粉末、违规带电商品

### 2. 图片优化
- 主图用场景图 + 促销标签
- 副图包含尺寸、细节
- 避免出现中文字样

### 3. 定价技巧
- 定价包含佣金和交易手续费
- 前期用引流款冲销量
- 后期用利润款赚钱

### 4. 物流选择
- 国内直邮：适合新手，成本低
- 海外仓：适合有稳定销量的卖家
